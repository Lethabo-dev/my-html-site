My Journey of Learning HTML

HTML stands for HyperText Markup Language. It is used to create the structure and content of websites. I am learning HTML to understand how webpages are built and how different elements work together.

Why Learning HTML Is Important

Learning HTML is an important first step in web development. It allows me to create headings, paragraphs, images, links and lists. These elements help organise information and make websites easier to use.

What I Am Learning

Some of the HTML skills I am currently practising include:

  • Creating headings and paragraphs
  • Adding images and links
  • Creating ordered and unordered lists

Steps I Follow When Creating a Webpage

  1. Create an HTML file in VS Code.
  2. Write the basic HTML structure.
  3. Add content, save and test the webpage in a browser.

To learn more about HTML, visit the official MDN HTML documentation.
